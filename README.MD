# 打工模拟器 v4.0 — 坤城篇

一款基于控制台的打工经营模拟游戏，在虚构城市「坤城」中体验打工人的酸甜苦辣。

> **叙事主题**：「在一个人人都想往上爬的城市里，你要成为什么样的人？」

---

## 🚀 快速开始

### Windows
双击 `打工模拟器.exe` 启动（含 ANSI 转义支持，推荐 Windows Terminal）

### 编译运行
```bash
gcc -o 打工模拟器.exe 源码/打工模拟器.cpp -lm -Wall -fexec-charset=GBK
```

- Web 版（旧版，不再更新）：https://ciallo0721-cmd.top/work/

## 🎮 游戏特色

### v4.0 坤城篇 新内容
- **时间槽系统** — 每天 3 个时段（上午/下午/晚上），取代旧能量制
- **打工难度模式** — 摸鱼/普通/加班/拼命，风险和回报成正比
- **打工微型事件** — 18 种随机事件，40% 触发率，含分支选择
- **每日日报结算** — 收入统计 + 生活成本扣除 + 夜间恢复
- **坤城世界观** — 虚构沿海城市，5 个城区，约 300 万人口
- **每日生活成本** — 房租 + 餐饮，随等级增长

### 核心系统
- **任务系统**：出租车、程序员、企业家等 10 种打工任务
- **技能系统**：10 项可升级技能，影响任务效率和收入
- **商城/家具**：购买家具和物品，提供被动收入加成
- **成就系统**：30 个成就（含叙事型 flavor text）
- **合成系统**：物品合成，创造更强装备

### 社交与状态
- **手机聊天室**：10+ AI 网友，含骗子、黑产等真实社交体验
- **好友系统**：10 位 NPC 好友，可互动送礼
- **状态系统**：饱食度/血量/精神，影响打工效率
- **季节系统**：春夏秋冬四季轮换，各有不同加成

### 经营要素
- **宠物系统**：5 种宠物，提供额外收入倍数
- **公司经营**：10 级公司升级，获得被动收入
- **股票市场**：5 只股票，实时波动
- **房产投资**：10 处房产，稳定收益
- **声望系统**：重置游戏获得永久加成
- **福布斯排行榜**：记录全服财富排名

### 编译说明

推荐使用 MSYS2 MinGW 编译：
```bash
MSYS_NO_PATHCONV=1 gcc -o 打工模拟器.exe 源码/打工模拟器.cpp -lm -Wall -fexec-charset=GBK
```

> `-fexec-charset=GBK` 确保中文在 Windows CMD 中正常显示
