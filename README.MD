# 打工模拟器 v5.0 — 坤城篇 · TUI 版

一款跑在终端里的打工经营模拟游戏。在虚构城市「坤城」中体验打工人的酸甜苦辣。

> **叙事主题**：「在一个人人都想往上爬的城市里，你要成为什么样的人？」

---

## 🚀 快速开始

### Windows
双击 `打工模拟器.exe` 启动。

**推荐 Windows Terminal**（宽度 ≥ 110 列、高度 ≥ 30 行效果最佳）。
传统 CMD 也能跑，但建议把窗口拉大一点，并把字体设为 Consolas + 新宋体。

### 编译
```bash
g++ -O2 -std=c++14 -o 打工模拟器.exe 源码/打工模拟器.cpp -lm
```
或者直接双击 `源码/build.bat`。

> ⚠️ **v5.0 起必须用 UTF-8 编译，不要加 `-fexec-charset=GBK`。**
> TUI 走 UTF-8 + ANSI 直出，加 GBK 会报
> `converting to execution character set: Illegal byte sequence`，
> 并连带刷出满屏 `tui_stream_reset was not declared`。

## 🖥️ 什么是 TUI

比纯 CLI 高一级，比 GUI 轻。整个游戏跑在一个带边框的字符界面上：

```
┌─ 档案 ──────────────────┐ ┌─ 今日 ──────────────────────────────┐
│ 匿名玩家          Lv.7  │ │ 时间槽 上 下 晚  还能干活   收入 +860 │
│ 坤币 48,250             │ │ 坤城指数 1240  +2  ▇▅▃▅▅▁▅▇█▅▁▆▅▆▇ │
│ 时间 上 下 晚           │ └─────────────────────────────────────┘
│ ─────────────────────── │ ┌─ 主菜单 ───────────────────────────┐
│ 饱食 █████░░░░░░  46    │ │ >  1 查看状态   2 打工赚钱  3 商城  │
│ 血量 ████████░░░  78    │ │    4 技能系统   5 背包物品  6 任务  │
│ 精神 ███░░░░░░░░  32    │ └─────────────────────────────────────┘
└─────────────────────────┘
```

**能做的事**
- 方向键在菜单里移动，回车进入，数字键直接快选，Q 退出
- 左侧常驻状态栏：等级、坤币、时间槽、五条属性、资产概览、坤城指数走势
- 顶部实时天数/季节/声望，底部按键提示条
- 所有老页面（技能 / 背包 / 任务 / 宠物 …）自动嵌进内容面板，支持 PgUp / PgDn 翻阅

## 🎮 游戏特色

### 核心系统
- **任务系统**：出租车、程序员、企业家等 10 种打工任务
- **技能系统**：10 项可升级技能，影响任务效率和收入
- **商城/家具**：购买家具和物品，提供被动收入加成
- **成就系统**：30 个成就（含叙事型 flavor text）
- **合成系统**：物品合成，创造更强装备

### 时间与难度（v4.0 起）
- **时间槽系统** — 每天 3 个时段（上午/下午/晚上），取代旧能量制
- **打工难度模式** — 摸鱼/普通/加班/拼命，风险和回报成正比
- **打工微型事件** — 18 种随机事件，40% 触发率，含分支选择
- **每日日报结算** — 收入统计 + 生活成本扣除 + 夜间恢复
- **每日生活成本** — 房租 + 餐饮，随等级增长

### 社交与状态
- **手机聊天室**：10+ AI 网友，含骗子、黑产等真实社交体验
- **好友系统**：10 位 NPC 好友，可互动送礼
- **状态系统**：饱食度/血量/精神，影响打工效率
- **季节系统**：春夏秋冬四季轮换，各有不同加成

### 经营要素
- **宠物系统**：5 种宠物，提供额外收入倍数
- **公司经营**：10 级公司升级，获得被动收入
- **房产投资**：10 处房产，稳定收益
- **声望系统**：重置游戏获得永久加成
- **福布斯排行榜**：记录全服财富排名

| GitHub | https://github.com/ciallo0721-cmd/Work-Simulator |

### 架构简述

`源码/tui.h` 是独立的界面层，不碰游戏逻辑：

- **画布**：`TuiCell` 数组双缓冲，UTF-8 + CJK 宽字符对齐
- **刷新**：逐行比对，只重画变化的行，不闪屏
- **按键**：`_kbhit`/`_getch` 轮询，支持方向键 / Home / End / PgUp / PgDn
- **组件**：边框、面板、进度条、迷你走势、带 Y 轴折线图、输入行
- **printf 捕获**：`#define printf tui_printf`，老页面零改动渲染进内容面板

### 自检（开发用）

```bash
# 渲染指定页面到 stdout（1=主菜单 2=股票 3=流式子页）
TUI_SELFTEST=1 TUI_FRAME=2 ./打工模拟器.exe > dump.bin

# 按键回放跑完整链路（U/D/L/R 方向键，~ 回车）
TUI_AUTOKEYS="9DDB" ./打工模拟器.exe
```
