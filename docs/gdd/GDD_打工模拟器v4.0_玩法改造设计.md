## 1. 设计支柱

> 以下3条是不可妥协的玩家体验目标。每个设计决策必须至少满足其中一条。

### 支柱 A：每天都是一次冒险
**"我不确定今天会发生什么，但我想试试。"**

- 每次打开游戏，玩家面对的不是重复菜单，而是"今天要怎么过"的决策
- 随机事件不是偶尔触发，而是每天的核心体验
- 玩家在结束一天时应该有一个"故事"可讲

### 支柱 B：每个选择都有代价
**"如果我选了这条路，另一条路就走不了了。"**

- 不存在"全都要"的最优解
- 时间、精力、金钱三者始终互斥
- 短期收益和长期成长的张力贯穿始终

### 支柱 C：系统互相认识
**"我的宠物居然影响了股票？我的聊天室朋友能帮我找工作？"**

- 任意两个系统之间至少有一个有意义的交叉点
- 玩家的行动会产生连锁反应
- 发现系统间隐藏联动是深层乐趣

## 2. 核心循环改造：打工日系统

### 2.1 问题诊断

**现有循环**：
```
菜单 → 选择打工 → 获得金钱 → 回到菜单 → 重复
```

这是一个**无摩擦、无节奏、无叙事**的点击循环。玩家感觉不到"一天"的存在。

### 2.2 新设计：时间槽系统

#### 概念

将"能量(energy)"替换为**"每日时间槽"**。一天有 **4 个时间段**（上午 / 下午 / 傍晚 / 夜晚），每个时间段玩家选择一个行动。

```
┌─────────────────────────────────────────────┐
│              一天的结构 (4 时间段)             │
├──────────┬──────────┬──────────┬─────────────┤
│  上午    │  下午    │  傍晚    │   夜晚      │
│ 06-12   │  12-18   │  18-21   │   21-24     │
├──────────┼──────────┼──────────┼─────────────┤
│ 打工     │ 打工     │ 社交     │  休息       │
│ (出租车) │ (程序员) │ (聊天室) │  (恢复)     │
└──────────┴──────────┴──────────┴─────────────┘
                          ↓
              每日结算 → 日报 → 新的一天
```

#### 玩家在每个时间段的选择

| 行动类型 | 消耗 | 收益 | 示例 |
|----------|------|------|------|
| **打工** | 1时间段 + 饱食度-6 + 血量风险 | 坤币 + 经验 | 出租车、程序员、企业家 |
| **学习** | 1时间段 + 金钱(学费) | 技能经验 | 报培训班、看书、拜师 |
| **社交** | 1时间段 | 好友度 + 信息(隐藏机会) | 聊天室、拜访好友、约会 |
| **投资** | 1时间段 + 金钱 | 被动收入/资产增值 | 看盘交易、看房、公司管理 |
| **探索** | 1时间段 + 精神消耗 | 随机事件/隐藏奖励 | 街头闲逛、神秘探险 |
| **休息** | 1时间段 | 血量+20 精神+15 饱食度-3 | 在家休息、去医院、做SPA |

#### 核心张力

玩家一天只有 **4 个时间段**，但需要同时满足：
- **赚钱**（至少1-2次打工才能维持生活）
- **成长**（学习提升技能，否则后期收入跟不上）
- **社交**（维护关系，不然错过隐藏机会）
- **恢复**（不休息会累积debuff）

**策略分歧点**：
- 激进型玩家：打工4次 → 钱多但状态崩 → 第二天被迫休息
- 平衡型玩家：打工2次 + 学习1次 + 社交1次 → 稳步成长
- 投机型玩家：打工1次 + 投资1次 + 探索2次 → 赌随机事件

### 2.3 每日结算与日报

每天结束时（夜晚时段结束后），触发结算：

```
═══════════════════════════════════════
         📋 第 42 天 结算报告
═══════════════════════════════════════
  💰 今日收入：     +3,200 坤币
  📈 被动收入：       +450 坤币
  🍔 食物消耗：       -300 坤币
  💸 维护费用：       -150 坤币
  ─────────────────────────────
  💎 净收益：       +3,200 坤币
  ⭐ 获得经验：        180 EXP
  
  🎯 今日成就：完成第 50 次出租车任务！
  📰 今日新闻：股市大涨，你的腾讯股票 +12%
  ⚠️ 状态变化：精神-8，目前62（正常）
  
  🔮 明日预告：天气预报说明天有招聘会
                （打工收入+20%）
═══════════════════════════════════════
```

日报的作用：
1. **叙事收束** — 给玩家"过完一天"的满足感
2. **明日预告** — 提供第二天策略的提示（钩子效应）
3. **进度可视化** — 让长期目标（100级/百万富翁）看起来更近

### 2.4 状态系统重新设计

现有状态系统的问题是：它只是"记得吃饭/睡觉"的琐事。新设计让状态变成**策略杠杆**。

| 状态 | 范围 | 高状态效果 | 低状态效果 | 自然衰减 |
|------|------|-----------|-----------|---------|
| **饱食度** | 0-100 | 打工收入×1.3（吃饱有力气） | 收入×0.7，概率晕倒（跳过1时段） | -6/打工, -3/休息 |
| **血量** | 0-100 | 可以接"危险"高收益任务 | 无法接危险任务，有概率住院 | 打工风险扣血 |
| **精神** | 0-100 | 学习效率×1.5，探索出稀有事件 | 幻觉(菜单乱码)，社交失败率高 | -8/天固定，打工额外-5 |
| **疲劳度** | 0-100 | — | 连续打工超过2次开始累积，影响所有成功率 | 休息时清零 |

> **设计原则**：状态不应只是"避免死亡"的约束，而应该是"我想保持高状态以获得加成"的正向激励。

### 2.5 打工任务改造

#### 现有任务表分析

| 任务 | 等级 | 收入 | 能量 | 成功率 | 效率(收入/能量) |
|------|------|------|------|--------|-----------------|
| 出租车司机 | 1 | 50 | 5 | 90% | 10.0 |
| 伐木工人 | 2 | 100 | 10 | 80% | 10.0 |
| 外卖配送 | 3 | 200 | 15 | 85% | 13.3 |
| 餐厅服务生 | 5 | 300 | 20 | 75% | 15.0 |
| 程序员 | 8 | 500 | 25 | 70% | 20.0 |
| 股票交易员 | 10 | 800 | 30 | 60% | 26.7 |
| 房地产经纪人 | 15 | 1200 | 35 | 65% | 34.3 |
| 企业家 | 20 | 2000 | 40 | 55% | 50.0 |
| 投资者 | 25 | 3000 | 45 | 50% | 66.7 |
| 神秘探险 | 30 | 5000 | 50 | 40% | 100.0 |

> **发现**：效率从 10 飙升到 100，后期任务性价比是前期的 10 倍。这是可行的（后期应有优势），但缺少"为什么我还要做低级任务"的理由。

#### 新设计：打工任务分级

将现有15个任务扩展为更丰富的层级，并加入**任务变体(variants)**：

```
打工任务 = 基础任务 × 难度模式 × 状态加成 × 技能加成
```

**难度模式**（玩家在接任务时选择）：

| 模式 | 收入倍率 | 风险 | 消耗 |
|------|---------|------|------|
| 摸鱼模式 | ×0.6 | 0%失败率 | 饱食度-3, 精神-3 |
| 普通模式 | ×1.0 | 基准失败率 | 饱食度-6, 精神-5 |
| 加班模式 | ×1.5 | 失败率×1.5 | 饱食度-9, 精神-8, 疲劳+20 |
| 拼命模式 | ×2.2 | 失败率×2.0, 血量-15 | 饱食度-12, 精神-15, 疲劳+35 |

> **决策点**：周末可以用"拼命模式"冲一波，但周一就得"摸鱼"恢复。玩家自己管理节奏。

### 2.6 新核心循环总结

```
┌─────────────────────────────────────────────────────┐
│                    会话级循环                          │
│                                                       │
│  进入游戏 → 查看日报(明日预告) → 决定今日策略           │
│      ↓                                                │
│  ┌─────────────────────────────────────┐             │
│  │       一天 = 4 个时间段              │             │
│  │  上午   下午   傍晚   夜晚           │             │
│  │   ↓      ↓      ↓      ↓            │             │
│  │  打工   学习   社交   休息           │             │
│  │  (选模式)(选技能)(聊天室)(恢复状态)   │             │
│  └─────────────────────────────────────┘             │
│      ↓                                                │
│  每日结算 → 随机事件 → 成就检查 → 存档                 │
│      ↓                                                │
│  "要不要再来一天？" ← 钩子（明日预告）                  │
└─────────────────────────────────────────────────────┘

长期循环：每天 → 每周(7天) → 每季(30天) → 每年
       打工    周日结算    赛季事件   周年庆
```

## 3. 风险/回报决策系统

### 3.1 打工失败不再是"少赚钱"

当前设计：打工失败 = 收入降低（乘以成功率），这不够刺激。

**新设计：打工 = 迷你叙事事件**

```
══════════════════════════════════
  正在打工：程序员（加班模式）
══════════════════════════════════

  📋 任务：修复线上Bug
  ⏱️  进度：████████░░ 80%
  
  突然！产品经理临时改了需求...
  
  [1] 接受需求变更（收入+30%，精神-10）
  [2] 拒绝需求变更（收入正常，但有概率被投诉）
  [3] 假装没看到（50%概率无事发生，50%概率被罚钱）
  
  你的选择：_
══════════════════════════════════
```

打工过程中随机触发 **1-2 个微型事件**，让每次打工都有叙事感。事件类型：

| 事件类型 | 触发条件 | 选项A | 选项B | 选项C |
|----------|---------|-------|-------|-------|
| 老板加活 | 加班/拼命模式 | 接受(收入↑精神↓) | 拒绝(关系↓) | 推荐同事(魅力检定) |
| 同事求助 | 任意模式 | 帮忙(好感度↑时间↑) | 拒绝(无事) | 敷衍(智力检定) |
| 意外发现 | 探索型任务 | 深入(风险高回报高) | 报告(稳定小回报) | 私藏(道德↓大回报) |
| 客户刁难 | 服务型任务 | 忍耐(精神↓) | 反击(魅力检定) | 找经理(领导力检定) |

> 每个事件消耗 1 次选择，不占额外时间段。这让打工从"按按钮"变成"做选择"。

### 3.2 高风险高回报任务链

引入**连锁任务**：完成前置任务后才解锁的高回报特殊任务。

```
例：程序员任务链
  普通打工(程序员 Lv8) 
    → 完成5次后解锁「接私活」(收入2×, 但占用夜晚时段)
      → 完成3次私活解锁「创业做独立游戏」(一次性投入10000, 
         30天后结算，可能大赚也可能暴死)
```

每个职业后期都有独特任务链，构成玩家的"职业故事线"。

### 4.2 关键新交互详解

#### 交互1：宠物协助打工

| 宠物 | 协助效果 | 触发条件 |
|------|---------|---------|
| 猫 | 程序员任务成功率+15% | 在家办公类任务 |
| 狗 | 外卖/快递任务收入+20% | 外出跑腿类任务 |
| 鹦鹉 | 社交类任务魅力检定+10 | 服务/销售类任务 |
| 龙 | 随机双倍收入(5%概率) | 任意任务 |
| 凤凰 | 打工失败时血量不扣 | 危险任务 |

#### 交互2：好友组队打工

高好感度好友可以"组队"打工：
- 出租车司机 + 好友组队：双人拼车，收入×1.4
- 程序员 + 好友组队：结对编程，成功率+20%
- 但消耗的好友的"当日时段"（好友也有每日限制）

#### 交互3：聊天室 → 隐藏机会

聊天室不仅社交，还是**信息渠道**：

| 聊天室消息类型 | 触发效果 |
|--------------|---------|
| "听说XX股票要涨" | 该股票当日波动率+30%（可能是真的也可能是假的） |
| "XX公司在招人" | 临时解锁一个高收益任务（仅当日有效） |
| "黑市有批便宜货" | 商城出现限时折扣商品 |
| "你被举报了" | 骗子事件，可能被骗钱 |

> 分辨真假消息需要"智力"技能检定。高智力玩家能从语气判断可信度。

#### 交互4：公司IPO

公司达到最高级(10级)后，可以"上市"：
- 公司转化为一支新股票（获得大量初始股份）
- 公司收入变成股票分红
- 但股价受市场波动影响，可能跌

## 5. 经济平衡方案

### 5.1 当前经济模型问题

```
收入来源：打工(主力) + 被动收入(家具+公司+房产+宠物) + 股票
支出：食物 + 商城购物(一次性) + 公司升级(一次性)

问题：支出基本是一次性的，收入是持续的 → 经济必然通胀
```

### 5.2 新经济模型：持续泄洪口

引入 **3 类持续性支出**：

#### A. 生活成本（每日自动扣除）

| 项目 | 每日费用 | 说明 |
|------|---------|------|
| 房租 | 50 坤币 | 基础档 |
| 伙食 | 30 坤币 | 温饱线 |
| 水电 | 20 坤币 | 基础 |
| **基础合计** | **100 坤币/天** | 即使什么都不做也要花 |
| | | |
| 拥有房产后 | 0(住房) + 30(伙食) + 20(水电) = 50/天 | 买房省房租 |
| 高级公寓 | 200/天(物业费) | 但休息恢复效率×2 |
| 豪华别墅 | 500/天(维护费) | 休息恢复效率×3, 声望加成 |

> **决策点**：买房不是纯收益，高档次住房维护费也高。升级生活方式有代价。

#### B. 设备折旧

已购买的家具/设备有 **耐久度**：

| 物品 | 耐久度 | 每30天维修费 | 不修的后果 |
|------|--------|-------------|-----------|
| 电视 | 100 | 30 坤币 | 被动收入-50% |
| 工作台 | 80 | 50 坤币 | 打工效率-10% |
| 游泳池 | 60 | 200 坤币 | 精神恢复-50% |
| 黄金马桶 | 120 | 100 坤币 | 声望加成消失 |

> 这解决了"买完家具就再也用不到商城"的问题。

#### C. 通胀机制

每完成30天（一个季度），所有物价上涨 `[PLACEHOLDER: 3%]`。
- 打工收入同步上涨（工资随通胀调整）
- 但存款的实际购买力下降
- **这迫使玩家投资而非囤积现金**

### 5.3 收入/支出平衡曲线

```
       坤币
        ↑
  5000  ┤                                    ╱ 打工收入
        ┤                                ╱╱
  3000  ┤                          ╱╱╱╱
        ┤                    ╱╱╱╱
  1500  ┤              ╱╱╱╱
        ┤        ╱╱╱╱               ─ ─ 生活成本+维护
   500  ┤  ╱╱╱╱
        ┤╱────────────────────────────────────→ 天数
        0    10    20    30    40    50
             ↑                  ↑
         生存压力期          财富自由拐点
        (策略最重要)       (可追求高风险玩法)
```

> 前20天是**生存压力期**：每个时间段的选择都重要，一步错可能欠债。  
> 20-40天是**策略分化期**：不同职业路线的差异开始显现。  
> 40天后是**自由探索期**：钱不再是问题，追求成就和稀有内容。

## 6. 职业专精路线

### 6.1 为什么需要专精

当前：玩家可以所有技能升满 → 没有重玩价值 → 所有人都一样。

新设计：技能点有限 + 路线锁定 = 不同档玩不同路线。

### 6.2 三大职业路线

| 路线 | 核心技能 | 核心任务 | 优势 | 劣势 | 终极目标 |
|------|---------|---------|------|------|---------|
| 🏃 **实干派** | 速度+力量+耐力 | 出租车→外卖→伐木→神秘探险 | 稳定现金流，前期强 | 后期增长慢 | 探险王：发现隐藏地图 |
| 🧠 **智力派** | 智力+创造力+管理 | 程序员→交易员→投资者→企业家 | 后期爆发力强 | 前期穷，风险高 | 科技巨头：公司上市 |
| 💬 **社交派** | 魅力+谈判+领导力 | 服务生→经纪人→企业家 | 信息优势，隐藏机会多 | 收入不稳定 | 人脉王：掌控聊天室网络 |

### 6.3 专精锁定机制

```
玩家初次到达等级10时，弹出：
══════════════════════════════════
  你已经在社会上站稳了脚跟。
  现在是时候选择你的职业方向了：
  
  [1] 实干派 — 靠双手创造未来
  [2] 智力派 — 靠头脑改变命运  
  [3] 社交派 — 靠人脉打开局面
  [4] 还没想好（可以以后再说）
══════════════════════════════════
```

选择路线后：
- 对应路线的核心技能上限从20提升到30
- 非核心技能上限从20降到15
- 解锁路线专属任务链和成就
- 路线可以花大量声望点数"转职"

### 6.4 路线专属内容

| | 实干派 | 智力派 | 社交派 |
|---|---|---|---|
| **专属宠物加成** | 狗(收入+)升级 | 猫(成功率+)升级 | 鹦鹉(魅力+)升级 |
| **专属事件** | 野外探险、宝藏发现 | 黑客竞赛、创业路演 | 名流晚宴、政商勾结 |
| **专属聊天室** | 工友群 | 技术论坛 | 商会群聊 |
| **专属成就** | "铁人"(连续打工30天) | "独角兽"(公司估值100万) | "万人迷"(20个好友) |

## 7. 新增内容设计

### 7.1 事件系统升级：日报头条

每天的"明日预告"不只是天气，而是真正的**游戏事件**：

| 事件类型 | 概率 | 效果 | 持续 |
|----------|------|------|------|
| 招聘会 | 15% | 所有打工收入+25% | 1天 |
| 暴雨 | 10% | 外出任务成功率-20%，外卖收入+50% | 1天 |
| 节日促销 | 20% | 商城8折 | 1天 |
| 股市震荡 | 8% | 所有股票波动翻倍 | 3天 |
| 严打黑产 | 5% | 聊天室黑产消失，骗子减少 | 7天 |
| 流感季 | 12% | 打工额外-10血量 | 3天 |
| 行业峰会 | 8% | 技能升级费用减半 | 1天 |

> 提前一天预告，让玩家能规划策略。这是"钩子效应"的关键。

### 7.2 成就系统改造

现有成就都是**计数型**（完成N次、拥有N个），新增**叙事型成就**：

```markdown
## 叙事型成就示例

"人精" — 在聊天室成功识破3个骗子的谎言
"赌怪" — 靠聊天室内幕消息炒股获利超过5000
"劳模" — 连续7天每天打工4次（四时段全打工）
"破产重生" — 从负债状态恢复到10000坤币
"跨界高手" — 转职后在新路线达到20级
"社交恐怖分子" — 同时有3位好友好感度达到满值
"锦鲤附体" — 一天内触发3个正面随机事件
"死神来了" — 经历猝死事件后幸存（精神从<5恢复到>80）
```

### 7.3 每周挑战（周日本）

每7天自动生成一个"周挑战"：

```
══════════════════════════════════
  📋 本周挑战：节俭周
  目标：本周总支出不超过500坤币
  奖励：下周所有收入×1.3
  进度：已花 320 / 500
══════════════════════════════════
```

每周挑战类型：

| 挑战名 | 目标 | 奖励 |
|--------|------|------|
| 赚钱周 | 周收入>10000 | 额外1000奖金 |
| 节俭周 | 周支出<500 | 下周收入×1.3 |
| 社交周 | 与5位好友互动 | 永久魅力+1 |
| 学习周 | 升级技能3次 | 技能点+2 |
| 冒险周 | 触发5次随机事件 | 神秘钥匙×3 |

## 8. 实现路线图

考虑到这是 C++ 控制台项目，改造应分阶段进行。以下按优先级排序：

### Phase 1：核心循环（最小可行改造）

| 优先级 | 功能 | 改动量 | 依赖 |
|--------|------|--------|------|
| P0 | 时间槽系统（替换能量） | 中等 | 无 |
| P0 | 每日结算日报 | 小 | 时间槽 |
| P1 | 打工微型事件（3-5种） | 小 | 无 |
| P1 | 生活成本每日扣除 | 极小 | 无 |
| P2 | 状态 → 策略杠杆（高状态加成） | 小 | 无 |

### Phase 2：系统互联

| 优先级 | 功能 | 改动量 | 依赖 |
|--------|------|--------|------|
| P0 | 聊天室 → 隐藏机会（股票消息/限时任务） | 小 | 无 |
| P1 | 宠物协助打工 | 小 | 宠物系统 |
| P2 | 好友组队 | 中等 | 好友系统 |
| P2 | 每周挑战 | 中等 | 时间系统 |
| P3 | 设备耐久/维修 | 中等 | 商城系统 |

### Phase 3：深度内容

| 优先级 | 功能 | 改动量 | 依赖 |
|--------|------|--------|------|
| P1 | 职业专精路线 | 大 | Phase 1 + 2 |
| P2 | 任务链系统 | 大 | 专精路线 |
| P2 | 公司IPO | 中等 | 专精路线 |
| P3 | 叙事型成就 | 小 | 无 |
| P3 | 打工难度模式 | 中等 | 时间槽 |

### 建议启动顺序

**Week 1-2**：时间槽 + 日报 + 生活成本 → **打通核心循环**  
**Week 3**：打工微型事件 + 状态加成 → **让打工有趣**  
**Week 4**：聊天室隐藏机会 → **系统开始互联**  
**Week 5-6**：每周挑战 + 宠物协助 → **中期目标**  
**Week 7-8**：职业专精路线 → **重玩价值**
