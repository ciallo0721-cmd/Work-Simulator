## 1. 叙事框架

### 1.1 核心主题

> **"在一个人人都想往上爬的城市里，你要成为什么样的人？"**

游戏在三个层面追问这个问题：

| 层面 | 玩家的选择 | 叙事回响 |
|------|-----------|---------|
| **生存** | 怎么赚钱活下去？ | 每一个省钱的决定都是对尊严的妥协或坚持 |
| **成长** | 走哪条路？跟谁同行？ | 职业路线不只是数值差异 — 是价值观的投票 |
| **归宿** | 爬到顶之后，然后呢？ | 终极成就不是数字，而是"你变成了谁" |

### 1.2 情感弧线

```
开局                                   中期                           后期
┌──────────────┐    ┌──────────────────┐    ┌──────────────────────┐
│ 迷茫+焦虑    │ →  │ 站稳+选择        │ →  │ 反思+定义            │
│              │    │                  │    │                      │
│ "我能在       │    │ "我找到了        │    │ "但我是为了什么      │
│  这里活下去   │    │  自己的路"       │    │  走到今天的？"       │
│  吗？"       │    │                  │    │                      │
│              │    │                  │    │                      │
│ 阶段时长:    │    │ 阶段时长:        │    │ 阶段时长:            │
│ Day 1-20     │    │ Day 21-60        │    │ Day 61+              │
└──────────────┘    └──────────────────┘    └──────────────────────┘
```

> **对标 GDD 经济平衡曲线**：情感阶段与经济阶段（生存压力期→策略分化期→自由探索期）对齐。当玩家不再为房租焦虑时，叙事自然转向"为什么要继续"的追问。

### 1.3 叙事设计支柱（与 GDD 三支柱对齐）

| GDD 设计支柱 | 叙事翻译 | 具体表现 |
|-------------|---------|---------|
| **A：每天都是一次冒险** | 坤城每天都有新鲜事 | 日报头条、聊天室风向变化、偶遇事件、季节事件 |
| **B：每个选择都有代价** | 选择的不只是策略，是立场 | 职业路线锁定价值观、好友不是资源是关系、道德选择影响 NPC 态度 |
| **C：系统互相认识** | 角色互相认识，消息在传播 | 聊天室泄漏内幕→股票波动、好友介绍工作→任务解锁、骗子被识破→黑产偃旗息鼓 |

## 2. 世界设定

### 2.1 坤城 — 一座没有名字的欲望都市

游戏世界是一座虚构的中国当代城市——**坤城**。它没有明确的地理位置，因为它是**所有打工人的城市**的提取物。

```
坤城的性格：

"坤城不问你的过去，只问你的价格。"

- 房价比工资涨得快
- 聊天室里什么人都有
- 今天还在路边摆摊的人，明天可能穿西装开奔驰
- 但也可能反过来
```

#### 坤城的时间感

- **一个游戏日 = 现实世界的浓缩切片**：坤城的一天包含了现实世界可能需要一周才能经历的事情
- **季节不只是背景**：春天招聘会多、夏天外卖爆单、秋天股市波动大、冬天人们更想宅（影响社交和打工类型）
- **城市在"成长"**：随着玩家等级提升，坤城也在变化 — 新的区域开放、新的 NPC 出现、旧的 NPC 可能离开

> **设计原则**：坤城是活的，但不显露。玩家感觉到的不是"世界在变化"的系统提示，而是"咦，那个经常在路边卖烤串的大叔怎么不见了"。

### 2.2 世界圣经 — 坤城事实基准

```markdown
## 坤城 World Bible v1.0

### 地理
- 坤城是一座虚构的沿海城市，约300万人口
- 城区分为：老城区（租金低）、CBD（白领聚集）、开发区（工厂+物流）、大学城、富人区
- 玩家初始住在老城区出租屋

### 时间线
- 游戏从"现在"开始，没有具体年份——永远是当代
- 每一天 = 1个游戏日
- 7天 = 1周（周日结算）
- 30天 = 1个季度
- 360天 = 1年

### 货币：坤币 (KBC)
- 1坤币 ≈ 现实1元人民币的购买力
- 基础日结工资（出租车司机）= 50坤币/时段 → 200/天（满打工）
- 基础日生活成本（租房+伙食+水电）= 100坤币/天
- 结论：必须至少打2次工才能维持生存

### 坤城的规则
- 股市是真的会亏钱的，没有"稳赚不赔"
- 聊天室里的骗子有时候比朋友更热情
- 升职不一定靠努力——有时候靠运气，有时候靠人脉
- 所有 NPC 都有自己的生活，他们不是在等玩家来找

### 禁止的设定（Banned Retcons）
- ❌ 永远不要出现"系统"或"GM"这类 meta 角色
- ❌ 永远不要让 NPC 知道自己是游戏角色
- ❌ 永远不要有一个"正确"的结局——每一种职业路线都是有效的
- ❌ 永远不要出现外星人、魔法、超能力——坤城的世界是现实的（虽然被戏剧化压缩）
```

## 3. 角色系统

### 3.1 角色设计原则

> **每个 NPC 不是"功能接口"，而是一个有自己生活的人。**

已有角色分为三类：
- **聊天室人物**（10人）：出现在手机聊天室中，各有身份和目的
- **好友列表人物**（10人）：可从聊天室或街头结识，发展深度关系
- **功能性 NPC**：每类打工的"老板/客户"、宠物、路人

### 3.2 聊天室核心角色（已有 → 深化）

#### 路人甲
```
## 角色：路人甲

### 身份
- **角色定位**：普通上班族，聊天室里的"气氛组"
- **核心创伤**：曾经也有梦想，但觉得"差不多就行了"
- **欲望**：想交几个聊得来的朋友
- **需求**：需要有人告诉他——你还没老，可以再试一次

### 声音支柱
- **词汇**：口头语，"还行吧""差不多""就这样呗"
- **节奏**：短句为主，偶尔冒出一句金句
- **避免话题**：不谈自己的梦想（怕丢人）
- **口头禅**："害，就是——"（话说到一半咽回去）
- **潜台词**：嘴上说无所谓，其实特别在意

### 他绝对不会说的话
- "让我们一起追逐梦想吧！"（太热血，他是温吞的）
- "我讨厌这个世界。"（他抱怨，但不愤怒）
- "你知道吗，其实我是——"（他不会主动倾诉）

### 参考台词
- "今天又加班到九点。老板说项目急，我看他也不急，就是习惯让我们陪着。" — 他的抱怨方式：陈述事实，不煽情
- "以前也想过去学点东西……后来发现学完了也没用。" — 他的自我否定方式
- "哎你上次说的那个培训班，我去看了。还没报名。再看吧。" — 他需要被推一把
```

#### 老陈
```
## 角色：老陈

### 身份
- **角色定位**：退休国企工人，聊天室里的"长辈"
- **核心创伤**：儿子在大城市工作，一年回来一次
```

## 4. 分支叙事：三大职业路线

### 4.1 路线选择 = 价值观投票

```
═══════════════════════════════════════════════════════
  你已经在这座城市站稳了脚跟。

  但现在的问题是——你要怎么往上走？

  有人靠双手，有人靠脑子，有人靠人脉。
  选一条路，没选的两条就暂时跟你无关了。

  [1] 实干派 — "我只相信做出来的东西。"
  [2] 智力派 — "知识就是杠杆。"
  [3] 社交派 — "你是谁不重要，你认识谁才重要。"
  [4] 还没想好（可以以后再说）
═══════════════════════════════════════════════════════
```

> **叙事设计**：每种路线的选择不只是数值差异，而是让玩家回答"你认为什么最重要"。这个答案会在后续的 NPC 对话、事件文本、甚至日报中反复被提及和挑战。

### 4.2 实干派路线：靠双手创造未来

**路线主题**：用身体丈量城市的每一寸，在最底层看到最多真相。

**叙事结构**：
```
Phase 1（入门）: 认识小明 → 学会"跑车的门道"
Phase 2（成长）: 和小红组队 → 发现隐藏区域（城市角落）
Phase 3（巅峰）: BOSS 挑战 → 面对小刚的"大项目"邀请
Phase 4（抉择）: 继续实干 or 跨界——发现实干派的局限
```

**关键 NPC 剧情片段**：

```
    + "没什么特别的。" [装酷]

        小明："我看你也不像超人。"
    
    + "你觉得这条路能走多远？" [远见]
        小明："（沉默了两秒）好问题。"
```

## 5. 打工微型叙事事件

### 5.1 设计原则

> 每一次打工不只是进度条滚动 — 它是一个30秒的迷你故事。

```
═══════════════════════════════════════════════════════
```

```
一个女人抱着孩子冲上车："机场！快！还有四十分钟起飞！"

你看了看导航 — 正常路线要五十分钟。
```

### 6.1 聊天室不只是社交接口——它是坤城的"新闻联播"

## 8. 环境叙事：坤城的脉搏

### 8.1 什么是"环境叙事"（在控制台游戏中）

> 控制台游戏没有3D场景，但环境叙事存在于：
> - **菜单氛围文案**：每个子系统的标题和说明
> - **系统消息的语气变化**：精神低时的"幻觉模式"（已有）
> - **物品/技能/成就的 flavor text**：不只是功能描述，是世界观碎片
> - **重复劳动中的微小变化**：第100次打工和第1次打工的不同体验

### 8.2 成就 flavor text 叙事设计

对标 GDD 第 7.2 节叙事型成就，每个成就不只是"你达成了X"——而是一句有味道的话：

## 附录A：对话实现提示

### A.1 控制台游戏的"演出"技巧

因为是纯文本控制台游戏，对话的"演出感"靠以下手段：

1. **延迟打印**：不是一次性显示整段对话，而是逐字/逐句出现（已有技术基础 — ANSI 控制码）
2. **空白行 = 呼吸**：关键台词前后加空行
3. **颜色 = 情绪**：已有 COLOR_RED/GREEN/YELLOW 等，关键台词用颜色强调
4. **NPC 名字的颜色区分**：骗子红、黑产绿、同城粉（已有）

### A.2 对话系统的扩展建议

```c

```

### A.3 对话字符串外化

所有 NPC 对话应存储在单独的数据结构/文件中，而非硬编码在逻辑里：

```c
// 建议：对话字符串池
typedef struct {
    const char* character_id;   // "路人甲"
    DialogContext context;      // CONTEXT_MORNING
    const char** lines;         // 该情境下的可选台词数组
    int line_count;
} DialogPool;
```

这样做的原因是：方便后续本地化、方便调整语气、方便多作者协作。
