# Work-Simulator 项目记忆

## 项目概况
- **名称**: 打工模拟器（Worker Simulator）
- **当前版本**: v4.0 - 坤城篇
- **语言**: C/C++ 控制台程序（单文件 ~5000行）
- **编译**: gcc 或 MinGW `gcc -o worker_sim.exe 打工模拟器.cpp -lm`
- **作者**: Ciallo0721-cmd
- **GitHub**: https://github.com/ciallo0721-cmd/Work-Simulator

## 设计文档
- `GDD_打工模拟器v4.0_玩法改造设计.md` — 玩法设计（时间槽、职业路线、系统互联等）
- `ND_打工模拟器v4.0_剧情改造设计.md` — 叙事设计（坤城世界观、角色语音支柱、打工事件等）

## 世界设定（v4.0 核心）
- **坤城**: 虚构当代中国沿海城市，约300万人口
- **城区**: 老城区 / CBD / 开发区 / 大学城 / 富人区
- **货币**: 坤币（KBC），1坤币≈1元
- **叙事主题**: "在一个人人都想往上爬的城市里，你要成为什么样的人？"
- **核心规则**: 无meta角色、NPC不知自己在游戏中、无"正确"结局、无超自然元素

## 关键架构决策
- 聊天室AI回复按**角色名+情境**匹配（非按类型通用模板）
- 成就系统从纯数值型改为叙事型flavor text
- 代码内所有系统文本均融入坤城世界观（任务/物品/任务/季节等）
