## 世界设定（v4.0 核心）
- **坤城**: 虚构当代中国沿海城市，约300万人口
- **城区**: 老城区 / CBD / 开发区 / 大学城 / 富人区
- **货币**: 坤币（KBC），1坤币≈1元
- **叙事主题**: "在一个人人都想往上爬的城市里，你要成为什么样的人？"
- **核心规则**: 无meta角色、NPC不知自己在游戏中、无"正确"结局、无超自然元素

## 关键架构决策
- **时间槽系统（daily_time_slots）已替换旧能量制为核心循环** — 每天3个时间槽（上午/下午/晚上），打工消耗1-2槽
- 打工时必须选择**难度模式**（摸鱼/普通/加班/拼命），影响收入倍率/时间消耗/健康/精神/猝死风险
- 时间槽耗尽自动触发 **day_end() 日报结算**，显示收入统计+扣生活成本+夜间恢复
- 打工微型事件系统：18个事件，40%触发率，含分支选择（灰色外包拒绝/遗落物品/黑中介等）
- 每日生活成本：房租=100+level×10，餐饮=80+level×5
- 聊天室AI回复按**角色名+情境**匹配（非按类型通用模板）
- 成就系统从纯数值型改为叙事型flavor text
- 代码内所有系统文本均融入坤城世界观（任务/物品/任务/季节等）
